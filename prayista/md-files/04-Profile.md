# Prayista — Screen Spec: Profile

**Flow:** Profile → Edit profile → Followed churches → Church detail (user side) → Recent orders → My sessions → Giving history → Share app → About Prayista

---

## 1. Profile

- Avatar (initials, e.g. "JD")
- Name: "Jane Doe"
- Tagline: personal favourite verse quote (e.g. "I can do all things through Christ" — Phil 4:13)
- Stats row (3 cells): Day streak (14), Churches (2), Badges (6)
- Menu list, each row a chevron link to its own screen:
  - Followed churches
  - Saved quotes
  - My sessions
  - Giving history
  - Recent orders
  - About Prayista

---

## 2. Edit profile

- Avatar (tap to change, implied)
- Fields: Username, Email, Favourite verse
- "Save changes" button

---

## 3. Followed churches

- Title: "Followed churches"
- List of churches, each row: logo/initials badge, church name, city/state, chevron
- "+ Follow another church" button at the bottom of the list

---

## 4. Church detail (user side)

- Banner image (gradient/photo)
- Church name (e.g. "Grace Community")
- Location + service times (e.g. "Austin, TX · Sundays 9 & 11 AM")
- "Following ✓" button (toggles to unfollow)
- Description text

---

## 5. Recent orders

- Title: "Recent orders"
- List, each row: product thumbnail, product name + size, order number + date, status badge (DELIVERED / IN TRANSIT)

---

## 6. My sessions

- Title: "My sessions"
- Tabs: Upcoming / Past
- List, each row: pastor name, date/time, session format (e.g. "Video call")
- (Shares layout with Book a Session → My Sessions screen)

---

## 7. Giving history

- Title: "Giving history"
- Highlighted summary card: total given this year (e.g. "$430 · This year")
- List of individual gifts below, each row: type + recipient (e.g. "Tithe · Grace Community"), date, amount

---

## 8. Share app

- Icon (share/arrow)
- Title: "Share Prayista"
- Description: "Invite friends and family to grow in faith together."
- Read-only invite link field (e.g. "prayista.app/invite/janedoe")
- "Share link" button

---

## 9. About Prayista

- Title: "About Prayista"
- Rows: Version (e.g. "2.4.1", not tappable), Terms & privacy policy, Help & support, Rate Prayista — each with chevron except Version
