# Prayista — Screen Spec: Media

**Flow:** Media hub (Sermons/Playlists) → Sermon detail → Now-playing player → Mini-player docked state → Playlists → Playlist detail → Song preview → Downloads

---

## 1. Media hub (Sermons | Playlists)

- Title: "Media"
- Tabs: **Sermons** (default) / Playlists
- List, each sermon row: thumbnail, title, speaker + duration, inline play icon
- Tapping a row opens Sermon detail

---

## 2. Sermon detail

- Banner image (gradient/photo)
- Title (e.g. "Faith Over Fear")
- Metadata: speaker · church · date (e.g. "Pastor Lee · Grace Community · Jul 14")
- Buttons: **Play** (primary) and **Download** (secondary, outlined)
- Description/summary text

---

## 3. Now-playing audio player

- "NOW PLAYING" label, top
- Large square artwork
- Title + speaker
- Progress bar with elapsed / total time (e.g. "14:02" / "38:00")
- Transport controls: rewind, play/pause (filled circle), forward
- "1.0x speed" button (playback speed selector)

---

## 4. Mini-player docked state

- Appears while browsing elsewhere (shown here docked at the bottom of the Sermons list)
- Compact bar: thumbnail, title + speaker, pause button
- A secondary mini icon-row below the player bar (play / pray / bible / notifications) — persistent quick-access row while media plays

---

## 5. Playlists list

- Title: "Playlists"
- List, each row: thumbnail, playlist name, song count (e.g. "Sunday Worship · 14 songs")

---

## 6. Playlist detail (song list)

- Banner (gradient)
- Playlist title (e.g. "Sunday Worship")
- Song list, each row: play icon, song title + artist, duration

---

## 7. Song preview player (30s)

- Large artwork
- Song title + artist
- "30s preview" label
- Progress bar (30-second scrubber)
- "Listen to full song" button — presumably deep-links out to a streaming service or unlocks full playback

---

## 8. Downloads / offline media

- Title: "Downloads"
- List, each row: thumbnail, title, file size + "Downloaded" status, checkmark
- Storage usage line at the bottom (e.g. "Storage used: 210 MB of 2 GB")
